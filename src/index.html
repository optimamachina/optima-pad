Welcome to Optima Pad

Write in the middle. Click anywhere outside it to drop a floating note.

  • Ctrl1 size · Ctrl2 color · Ctrl3 soft box
  • Ctrl4 or middle-click: fonts, themes, text size, backgrounds, doodles, recent notes
  • Ctrl + scroll to zoom around · CtrlL to lock with a password · CtrlF to find
  • Hold - for a divider · AltC ✓ · AltX ✗ · Ctrl- strike · Tab indents · - space starts a bullet · Del in a box removes the whole box
  • Drag an image's corner to resize it · drag a box's right edge to set its width · CtrlShiftT reopens the last closed note
  • CtrlAltO from anywhere: a quick little note · hover the top-left corner to pin a note on top · hover the name for a word count

Everything saves itself. CtrlS gives a note its name and home.
